# Dapper NHibernate API

A .NET 10 API project built with Dapper and NHibernate ORM.

## Project Overview

This project demonstrates integration of Dapper and NHibernate for data access in a modern .NET application.

## Technologies Used

- **.NET 10**
- **Dapper** - Lightweight ORM for database access
- **NHibernate** - Full-featured ORM framework
- **C#**

## Project Structure

The solution includes:
- Main API project using DapperNHibernate
- Configuration files for database connections and settings

## Getting Started

### Prerequisites

- .NET 10 SDK or later
- SQL Server or compatible database
- Visual Studio 2026 Community Edition or later

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/SangitaZare/angular-trainning.git
   ```

2. Navigate to the project directory
   ```bash
   cd DapperNHibernateApi
   ```

3. Restore dependencies
   ```bash
   dotnet restore
   ```

4. Configure your database connection in `appsettings.json`

5. Run the application
   ```bash
   dotnet run
   ```

## Configuration

Update `appsettings.json` with your database connection string and other settings.
